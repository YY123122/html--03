# CSS导航菜单实验
## 实验说明
本实验实现一级水平导航菜单、带下拉的二级导航菜单。
仅添加CSS样式，**没有修改HTML结构**。
### 用到知识点
1. CSS选择器：后代选择器、类选择器、并集选择器
2. 盒模型：margin、padding、border控制间距
3. display:inline-block实现横向排列
4. :hover伪类，鼠标悬浮切换背景、显示下拉菜单
5. position相对+绝对定位实现二级下拉菜单定位
6. CSS样式继承与优先级

## 文件列表
- 一级菜单.html：水平一级导航
- 二级菜单.html：带下拉二级导航
